  Task_17.md                             Write-up for Task 17

## Tasks


Task 15- Numerical Differentiation 
Vehicle speed from GPS positions ,Boda boda slowing at a junction 
Task 17 
ODEs - Euler Method 
Hot object cooling , Cup of tea cooling 

Each write-up in `docs/` covers the inputs and operation, the original
output, the effect of changing a parameter, an interpretation of the
results, and the modified real-world case.
