# Task 2 – NumPy Arrays and Numerical Computation

## 1. Mathematical Concept

A NumPy array stores the 24 hourly temperature readings as one numerical structure. The program calculates the daily mean, minimum and maximum, then converts every Celsius reading to Fahrenheit using F = 1.8C + 32.

## 2. Inputs and Mathematical Operation

The inputs are the 24 temperatures in degrees Celsius. The mathematical operations are the arithmetic mean, minimum, maximum and element-wise Celsius-to-Fahrenheit conversion.

## 3. Output and Interpretation

The mean represents the average temperature for the day. The minimum and maximum identify the coldest and warmest recorded hours. The converted array expresses the same readings in Fahrenheit.
